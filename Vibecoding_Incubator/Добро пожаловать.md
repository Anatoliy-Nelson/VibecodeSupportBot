# Добро пожаловать в базу знаний!

Это ваше персональное хранилище знаний, созданное LLM wiki-агентом Qwen.

## 📂 Начало работы

- [[QWEN]] — инструкции и принципы работы с базой
- [[index]] — главная навигационная страница
- [[log]] — журнал всех изменений

## ✏️ Как использовать

1. **Создание заметок**: Просто создайте новый `.md` файл в этой папке
2. **Ссылки**: Используйте `[[Название заметки]]` для双向ных ссылок
3. **Теги**: Добавляйте `#тег` для категоризации
4. **Журнал**: Все новые записи автоматически добавляются в [[log]]

## 🗑️ Удаление

Когда будете готовы, удалите эту заметку и сделайте хранилище своим собственным.
